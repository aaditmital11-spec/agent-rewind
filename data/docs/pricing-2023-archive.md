# Archived: Nimbus Cloud pricing (2023)

This page is kept for historical reference only. These prices are no longer offered.

## Pro plan (2023)

In 2023 the Pro plan cost $19 per user per month and included 50 GB of storage and 300 API requests per minute.

## Business plan (2023)

The Business plan cost $45 per user per month. It was renamed to Team in 2024.
